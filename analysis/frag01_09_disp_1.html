Read and prepare the data

The data used here is from a spatially-explicit metacommunity simulation model developed by Stav Gelber. From the entire simulation 30 virtual “samples” were taken from scenarios with high vs. low fragmentation but equal habitat amount.

#setwd("..")
simdat1 <- read.table("data_raw/dispersal_4_rep_1_output_sample.csv", header = TRUE,
                      sep = ",")
#simdat1 <- simdat1 %>% select(-X)

Filter high and low fragmentation scenarios at two different time points

Time point t0 is directly after landscape modification happened, i.e. after certain grid cells were converted from habitat to matrix. So here, we only see what we call geometric fragmentation effects. At t0 all differences between high and low fragmentation scenarios can be attributed to spatial sampling only, but not to changed demographic processes in small and isolated habitat fragments.

Time point tend is at the end of the simulation, i.e. with long-term metacommunity dynamics in a fragmented landscape. The findings here show what we call geometric plus demographic effects.

sim1 <- 1
sim2 <- 9
t0 <- 41
tend <- 100

frag_low_t0 <- simdat1 %>% filter(sim_id == sim1 & step == t0)

When we use the spatial and sample-based rarefaction curves of mobr the pattern remains the same as with non-spatial rarefaction curves. While these ssBR-curves accumulate samples by proximity, they still compare scenarios by sampling effort measured by no. of samples, i.e., they still do not consider the extent of a given no. of samples. For this purpose, we developed spatially-explicit rarefaction curves (called spexSBR at the moment, but this can be debated …)

Calculate spatially explicit sample-based rarefaction curves (spexSBR)

With convexhull-Algorithm

spexSBR_frag_low_t0 <- rarefaction(spec_frag_low_t0, method = "spexSBR", coords = xy_frag_low,
                                latlong = F, spat_algo = "convexhull")

spexSBR_frag_high_t0 <- rarefaction(spec_frag_high_t0, method = "spexSBR", coords = xy_frag_high,
                                latlong = F, spat_algo = "convexhull")

spexSBR_frag_low_tend <- rarefaction(spec_frag_low_tend, method = "spexSBR", coords = xy_frag_low,
                                  latlong = F, spat_algo = "convexhull")

spexSBR_frag_high_tend <- rarefaction(spec_frag_high_tend, method = "spexSBR", coords = xy_frag_high,
                                  latlong = F, spat_algo = "convexhull")

Create dataframe for plotting with ggplot

spexSBR_length <- length(spexSBR_frag_low_t0)

spexSBR_data <- data.frame(area = as.numeric(c(names(spexSBR_frag_low_t0),
                                               names(spexSBR_frag_high_t0),
                                               names(spexSBR_frag_low_tend),
                                               names(spexSBR_frag_high_tend))),
                           S       = c(spexSBR_frag_low_t0,
                                       spexSBR_frag_high_t0,
                                       spexSBR_frag_low_tend,
                                       spexSBR_frag_high_tend),
                           fragmentation = rep(c("Low", "High","Low","High"),
                                         each = spexSBR_length),
                           time = rep(c("t0","t0","tend","tend"),
                                        each = spexSBR_length)
                        )

Plot the spexSBR curves

ggplot(spexSBR_data, aes(area, S, color = fragmentation)) +
  geom_point() +
  geom_line() +
  facet_grid(~time) +
  ggtitle("Spatially-explicit rarefaction curve with convex-hull area")

Now, the curves control for extent (or total area sampled) which is estimated by the area of the convex-hull-polygon of a certain number of accumulated samples. Most notably, we see that at t0 the curves are very close, which indicates that in this case the higher richness in the high fragmentation scenarios results because of the higher extent covered by the 30 samples.

Finally, we want to know if the observed differences between the spexSBR curves for the high and low fragmentation scenarios are “significant” or not. For this purpose, we use a null-model approach based on randomly permuting samples between the fragmentation scenarios.

Calculate spexSBR differences and null-model with lower and upper bound

Get the distance / area values from the curve with the smaller extent

Since the coordinates to not change over time, the spatial effort from just one time step is needed.

spat_eff <- spexSBR_data %>%
  filter(fragmentation == "Low" & time == "t0") %>%
  select(area)
spat_eff <- as.numeric(spat_eff[[1]])
delta_t0 <- get_spexSBR_interval(comm1 = spec_frag_low_t0, coords1 = xy_frag_low,
                                 comm2 = spec_frag_high_t0, coords2 = xy_frag_high,
                                 spat_effort = spat_eff, nperm = 30)

delta_tend <- get_spexSBR_interval(comm1 = spec_frag_low_tend, coords1 = xy_frag_low,
                                   comm2 = spec_frag_high_tend, coords2 = xy_frag_high,
                                   spat_effort = spat_eff, nperm = 30)
delta_dat2 <- bind_rows(delta_t0, delta_tend)
delta_dat2$time <- rep(c("t0","tend"), each = length(spat_eff))
ggplot(delta_dat2, aes(spatial_effort, obs)) +
  geom_ribbon(aes(ymin = lower, ymax = upper), fill = "grey") +
  geom_line(aes(y = obs),linewidth = 2, color = "red") +
  geom_hline(yintercept = 0) +
  facet_grid(~time) +
  ylab("Delta S")

In these figures, the red lines are the observed differences between the spexSBR curves for t0 and tend. The grey ribbons are the confidence intervals from the the null-model, where samples are randomly permuted between high and low fragmentation scenarios.
